# 上海交通大学学生科技创新类大赛项目信息手册

本仓库用于整理和保存上海交通大学学生科技创新类竞赛相关资料。

## 当前文件

- **上海交通大学学生科技创新类大赛项目信息手册.docx**
  - 依据《上海交通大学自动化与感知学院本科生综合素质测评细则（2026版）》相关附件整理
  - 共收录 **78 项**学生科技创新类竞赛
  - 按原始目录分为：专项赛事、A 类、B 类、C 类、D 类
  - 每项赛事按照统一体例整理，包括：
    - 主办单位
    - 竞赛时间
    - 赛事简介
    - 报名方式
    - 竞赛内容
    - 参赛形式
    - 相关认定/加分信息（适用时）

## 内容范围

手册覆盖的赛事类型包括但不限于：

- 大学生创新创业类赛事
- “挑战杯”等综合科技创新赛事
- 软件与计算机类竞赛
- 人工智能、机器人、自动化与物联网类竞赛
- 集成电路、嵌入式、通信与电子信息类竞赛
- 数学建模、市场调查等数据分析类竞赛
- 结构设计、交通科技等工程实践类竞赛
- 上海交通大学校内科技创新类赛事

此外，文档附有**赛事速查总表**，便于按照赛事类别、报名时间和参赛形式进行快速筛选。

## 使用说明

建议在计划参加竞赛或制定学期科创计划时使用本手册进行初步筛选。

需要注意：

> 文档中的竞赛时间、报名方式、赛制及参赛要求主要反映 2024—2026 年的常态化安排。不同年份可能存在调整，实际报名和比赛安排应以当届竞赛官方通知以及上海交通大学、相关学院发布的通知为准。

## 资料来源与说明

本手册中的赛事信息根据公开渠道整理，包括相关竞赛官方网站、教育部门公开信息以及高校通知等。

本仓库主要用于**学习、资料整理和竞赛信息查询**，不构成任何赛事官方文件。
